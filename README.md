# Akara Joint — demo ecommerce website

## Run it
1. Extract the ZIP.
2. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
3. Open `index.html` in a browser, or use VS Code Live Server.

## JavaScript functionality
- Product catalogue and category filtering
- Add-to-bag, quantity controls, subtotal and cart persistence
- Sign-in and sign-up form validation
- Mock account registration saved in this browser
- Demo account sign-in and sign-out
- Checkout flow placeholder

## Important security note
This is a front-end learning/demo project. Mock user records (including passwords) are stored in browser localStorage and can be viewed or changed by the browser user. Do not enter real customer data or deploy this as production authentication. A real store needs a backend, secure password hashing, server-side validation, a database, order management and a payment provider.
